Anything that you want the reviewer to know

The aim of Dog-Eared Pages is to create a welcoming online space for readers who enjoy affordable second-hand books and unusual literary finds. I wanted the website to feel like a real independent bookshop, with a catalogue to explore and a map that helps visitors discover different areas of the shop.

One of the most interesting parts of the project was creating the interactive map using checkboxes, labels, and CSS pop-ups. It allows visitors to select markers and learn more about each area without needing JavaScript. Flexbox helps organise the navigation and content, while the mobile media query adapts the layout to smaller screens. CSS transitions add smooth visual effects to cards, navigation links, and images.

I also wanted to create a proper book catalogue, so I included a separate books.html page. It displays a collection of second-hand books in individual cards, with images, titles, authors, genres, prices, and descriptions of their condition. I used Flexbox to organise the book cards into a clear and structured layout, making the catalogue easier to browse. Each card also includes an order button, giving the page the feel of a real online bookshop.

My original idea was to develop a fully functional sales catalogue where customers could purchase available books directly. However, implementing the purchasing functionality would require additional scripting, which was outside the scope of the technologies permitted for this project. The separate order.html page serves a different purpose: it allows customers to request rare, unique, or unavailable books that are not listed in the catalogue.

With more time, I would add Google Fonts, improve the book search functionality, and I would add a search function to the book catalogue, implement sorting options to help visitors find books more easily, and integrate an order form directly into the catalogue so customers could order books without leaving the page.
